## 2. 傷害公式（完整版，含下限）

### 2.1 一般交戰傷害

```
攻'   = 兵種攻 × (1 + 武將攻/200)          // 只有被光環附住嘅隊才套武將項
相剋  = 1.3（攻方剋守方）／1.0（其他）      // 見 §4
基礎  = 攻' × 攻方數量 × 相剋 − 守方防 × 攻方數量
最終  = max(基礎, 0.1 × 攻方數量)          // 定案 3
減員  = floor(最終 / 守方單位HP)            // 最少 0
溢出  = 最終 − 減員 × 守方單位HP            // 溢出唔轉移去下一隊（切片從簡）
```

### 2.2 技能傷害（沿用 §3.6.2）

```
技能傷害 = 技能係數 × 技能屬性 × (1 + 武將攻/200)
減員     = floor(技能傷害 / (1 + 守方武將防/200) / 守方單位HP)
```

### 2.3 反擊

- 每單位每回合最多反擊 **1 次**（【攻】§3.6.1）。
- 反擊用同一公式，但**唔計相剋加成**（相剋 = 1.0）。
- 反擊同樣受 `0.1×數量` 下限保護。

### 2.4 文字算式證明：盾打盾唔會出負數（保留）

盾兵 攻 1.4、防 3.0、20 隻；無武將光環、無相剋：

```
基礎 = 1.4 × 20 × 1.0 − 3.0 × 20
     = 28 − 60
     = −32
最終 = max(−32, 0.1 × 20)
     = max(−32, 2)
     = 2
```

武將光環（攻 70）情況：基礎 = 1.4×20×1.35 − 60 = 37.8 − 60 = −22.2，最終仍然係 2。

> 副作用：盾打盾永遠只造成 `0.1×數量`，即「盾牆對盾牆」僵局。15 回合上限就係為此而設。

## 3. 出手序（含學者、神獸）

| 序位 | 兵種 | 速度 | 說明 |
|---|---|---|---|
| 0 | 武將光環結算 | — | 每回合開始，光環先套用到被附隊 |
| 1 | 騎兵 | 7 | 最快，先手切入後排 |
| 2 | 刀兵 | 6 | 快攻 |
| 3 | 神獸 | 6 | 與刀同速，排刀之後 |
| 4 | 弓兵 | 4 | 遠程（射程 3） |
| 5 | 學者 | 4 | 與弓同速，**排弓之後**（後手補刀） |
| 6 | 戟兵 | 4 | 克騎，排最後一組 4 速 |
| 7 | 盾兵 | 3 | 最慢 |

同速裁決：**騎 > 刀 > 神獸 > 弓 > 學者 > 戟 > 盾**（固定，唔用隨機）。

## 4. 相剋六角表（【鎖】Q2 已定，六條全部生效）

| 攻方 | 剋 | 倍率 | 標記 |
|---|---|---|---|
| 戟兵 | → 騎兵 | 1.3 | 【攻】已確認 |
| 學者 | → 弓兵 | 1.3 | 【攻】已確認 |

## 5. 勝負三層（定案 5）

| 優先 | 條件 | 判定 |
|---|---|---|
| 1 | 一方場上單位全部陣亡 | 另一方勝 |
| 1.5 | 同一回合雙方同時歸零 | 平 |
| 2 | 回合數到 **15** | 比較雙方**剩餘總 HP**，高者勝；相等則平 |

- HP 相同時唔比隊數、唔比殘血百分比，直接平。
- 15 回合係硬上限。

## 6. 武將光環規則（定案 1、2）

```
每場開始（佈陣階段）玩家指定一隊 = 光環隊
該隊：攻' = 兵種攻 × (1 + 武將攻/200)
      守' = 兵種防 × (1 + 武將防/200)
```

- 武將**唔佔 12 隊名額、唔佔格**。
- 光環隊被全滅 → 光環即失效，武將唔會變獨立單位。
- 技能由武將釋放，每回合 1 次，目標優先：射程內敵方學者 → 弓兵 → 其他。
- 一個武將只有一個光環隊；冇多光環疊加。

## 9. 實作提示（唔使照抄，但要滿足）

1. 資料結構：`UnitStack { type, count, hpPerUnit, hpCurrent, speed, atk, def, range, cellX, cellY, auraOwner? }`
2. 回合流程：`光環結算 → 按 §3 排序 → 逐單位 {移動+攻擊 / 等待 / 防禦} → 結算反擊（每單位 1 次）→ 檢勝負`
3. 數值集中喺 `balance.json`：`HERO_COEF=0.001`、`COUNTER_MULT=1.3`、`DMG_FLOOR=0.1`、`TURN_LIMIT=15` 四個常數可調；**靶兵 def=0 屬於測試 fixture，唔好放 `balance.json`**。
4. 隨機性：本切片**零隨機**（冇暴擊、冇閃避），TTK 可重現；要 seed 就固定 seed=0。
5. 錨點測試寫成獨立 test，唔依賴 UI，純函數輸入輸出。
6. 相剋表實作成**單向 map**（`counter[攻方] = 被剋方`），唔好用對稱矩陣，天然避免雙向誤實作。
