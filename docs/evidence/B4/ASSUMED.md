# B4 ASSUMED

這些是工作包沒有寫死、實作時自行決定的點。

1. 世界層用 CSS 定位現有 `public/art/board/city-placeholder.svg`，沒有接 pixi。佔位圖本身已是 2496×1440，縮放用畫面座標就滿足 G6。
2. 城外草地用 `#55603F`。倉內沒有 P0 `baked_base` 可取樣；佔位 SVG 背景透明，0.4 全景靠這層底色避免黑邊。
3. 1920 的世界層在同一 zoom 檔再乘 `screenW / 1280`（即 1.5），offset 用該檔的 `(144,0)`。只放大 offset、不放大世界時，校場在 1920 的 0.5 檔會伸出安全區左緣。
4. 右上圓鈕以中心 `(1228, 28/72/116)` 與 Ø40 為準。這組中心距是 44，Ø40 的視覺淨距是 4。規格另寫「間距 16」，與中心座標不能同時成立。
5. 爵位、聯盟沒有給寬高。爵位用 `92,60 100×18`。聯盟用 `92,80 100×10`、字級 10，底邊貼齊 y=90，避免蓋住排行。
6. 兵力 tab 沒有給寬高，沿用武將 tab 的 `64×26`，起點維持 `(78,376)`。
7. 五個聊天 tab 從 x=280 起，與輸入行對齊。輸入行 `(280,682) 383×30` 內含欄位 331 與發送 52，發送鈕不伸出聊天列。
8. 校場、點兵場沒有版面座標。放在安全區頂部 `(288,16) 168×36` 與 `(464,16) 184×36`。0.5 檔不壓 `gov` / `drill` / `gate_s`。
9. 隊列第三格假定為 `兵營 6級`、`05:00:00`、狀態排隊。`倉庫 13級` 假定為第二條在建，倒數 `02:15:00`。只讓在建倒數每秒跳，到 `00:00:00` 色條轉金，不把排隊升成在建。
10. 產量沒有示例。人口 `+12/時`、玉石 `+1/時`、刀幣 `+360/時`、糧與木 `+480/時`、鐵與石 `+240/時`。
11. 數值等寬用 `font-variant-numeric: tabular-nums`，字體堆疊用規格裡的黑體，不下載字體。
12. 解析度與 zoom 切換放在畫框外。畫框內不多一組矩形去壓三個主體。`/city?size=1920` 與 `/city?zoom=0.4` 可直接打開對應畫面。
13. 功能格視覺高度是 24 與 16，低於 32px 點擊下限，70px 面板也放不下三排互不重疊的 32px hit。`tokens.ts` 另記 hit 矩形給 `ui-check`；畫面上的功能格按鈕維持規格視覺尺寸，避免透明 hit 互相遮擋。
14. 完成色條用 `#C9A227`，在建 `#6E8B4F`，排隊 `#6B625A`，格間分隔線 `#1A120C`。
15. 武將／兵力兩個 tab 不隱藏區塊，只切高亮。版面同時保留武將卡與七行兵力。
