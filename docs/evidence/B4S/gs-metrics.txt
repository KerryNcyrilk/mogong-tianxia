# B4S 量測與執行期證據（本機頭less Chromium + CDP）

## GS2 寫入成本（dev 執行期，1280 窗）
- 批次法：100 次寫入為一組，共 1000 組 → 每組耗時再除以 100
  - p50 = 0.017 ms
  - p95 = 0.030 ms   ← 門檻 < 0.05 ms  PASS
  - p99 = 0.035 ms
  - max = 0.053 ms
- 單次 performance.now() 解析度為 0.1 ms，直接量單次會得 0/0.1，故改用批次正規化。
- 對照：20 萬次連續寫入總耗 3746 ms → 平均 0.0187 ms/次。
