## 2. 核心結論：新圖唔係現行 28×20 等軸平面

現行 `cityLayout.json` 用 2:1 菱形等軸投影（`px=(x−y)×48+1056`、`py=(x+y)×24+192`）。Iris 這張圖是**自由透視全景**（約 40–45° 俯視、帶地平線與山景、建築各自獨立角度），兩者不是同一個座標系。

把現行 31 區投影直接疊在新圖上（見 `overlay-current-layout-2496.png`），主要建築偏差如下（Δ 為新圖實際建築中心 − 現行投影中心）：

| 區塊 | 現行投影中心 | 新圖實際中心 | Δ |
| --- | --- | --- | --- |
| 池塘 | (1440,1200) | (2272,705) | (+832, −495)，969px |
| 市集 | (1896,732) | (1165,550) | (−731, −182)，753px |
| 南門 | (600,876) | (1018,400) | (+418, −476)，633px |
| 營房 | (1080,468) | (726,560) | (−354, +92)，366px |
| 校場 | (912,624) | (656,880) | (−256, +256)，362px |
| 官府 | (1512,828) | (1328,900) | (−184, +72)，198px |
| 農田 | (552,756) | (498,672) | (−54, −84)，100px |

偏差方向唔一致（池塘往東、市集往西、校場往西南），所以**冇一個統一縮放／平移可以對位**；要靠逐區重描。

另外兩點結構性差異：

1. 新圖只有**北門**（城門塔在北牆中段），畫面南側被裁到民居外圍，**冇南門**；而玩法 `gate_s`（南門＝出城入口）係硬需求。
2. 新圖把「宗廟／祠堂／書院」等都放在圍牆外的山坡與院落，31 區中 `shrine`／`grove_*`／`herb` 之類在新圖位置需要重新指定。

## 4. 兩個可行方案（要拍板）

**方案 A：新增顯示座標權威 `data/cityLayoutV3.json`**
- 保留 `cityLayout.json` 做玩法權威（不動紅線）；另立 v3 顯示座標檔，31 區逐區手描多邊形（或由 Iris 出標註）。
- 成本：31 區手描約 1 輪（我可做），之後 UI 加一層 v3 hit-test 切換。
- 好處：整個城市可點、hover 卡片、熱區高亮全部對得上真圖。

**方案 B：只做 8 熱區可點（最小改動）**
- 城市畫面只作背景＋8 個熱區可點，其餘區域靠左欄／底部按鈕進入（現時已可用）。
- 成本：小；但「點建築」的沉浸感只覆蓋 8 個點，且南門要改掛到北門塔或另畫出城牌。

我建議 **A**，因為 v3 是「換皮對位」的最終形態，B 只適合做臨時試玩。
