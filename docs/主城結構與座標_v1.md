## 1. 座標系（一句講清）

| 項 | 值 |
|---|---|
| tile | 96 px（**邏輯格闊**）；投影高 48 px（2:1 菱形） |
| 邏輯平面 | 28 × 20 = **2688 × 1920 px**（**只係規劃坐標，唔係渲染尺寸**） |
| 投影平面 | **2304 × 1152 px**（(28+20)×48 闊、(28+20)×24 高，四角為菱形尖） |
| Artboard（P0 底圖／灰盒） | **2496 × 1440 px**（左右各 96、上 192、下 96 邊距） |
| 原點 | 左上角；x 向右、y 向下 |
| 投影 | 2.5D 斜 45°、2:1 菱形：**邏輯格 96 闊 × 48 投影高**，同戰鬥 tile 96 對齊 |
| 錨點 | **所有 sprite 底部中心（foot anchor）**，世界 y 值以腳底為準 |
| 繪製排序 | `anchor.y` 由細至大（y 大者後畫＝在前） |

**成個流程分三層，唔好混：**

1. 邏輯格（x/y/w/h）＝規劃用，座標全部寫呢層。
2. 投影平面 2304×1152＝菱形化之後城市真正佔幾大。
3. Artboard 2496×1440＝Iris 真正要開嘅畫布，多出嘅邊用來擺北牆立面、屋簷、旗杆同南牆底座。

座標寫法：`(x, y, w, h)` 全部係 tile 數，`(x,y)` 係左上角。**唔准用像素寫佔地。**

## 3. 淨空規則（守住呢六條，就唔會走樣）

1. **校場內部（x5–9、y7–13）必須空白**：唔准建築、樹、NPC、裝飾；只准四角旗杆。
2. **官府院落內只准官府自身組件**（主殿、配殿、院牆、門樓、石階、院內草地花樹立石）。
3. **主幹道（x12–13、y5–17）唔准任何物件壓住**；路口位留 1 tile 空地。
4. **城牆內側 1 tile 係「地面草帶」，唔係淨空帶**（x1 / x26 / y1 / y18）：貼牆建築（民居、市場、宗廟、花樹、樹林）可以坐落草帶上，但地面要見至少 0.5 tile 連續草地，唔准全鋪石；城牆立面唔准被任何 sprite 遮超過 1/3 高。
5. **建築貼路擺**：外框要接住最近嘅石板路，唔准漂浮喺草地中間。
6. **間距只約束同類量產建築**：民居之間、資源田之間最少留 1 tile。地標建築（官府／市場／馬場／宗廟／營房／倉庫／兵營）之間可以互貼——原版本身就係密集院落式；實際要求改為**遮擋率**：上層 sprite 遮住鄰居主體立面 ≤ 25%，遮到窗／門／匾額即違規。

## 4. Sprite 落位規則（Iris 出圖前必讀）

- **錨點**：底部中心。出圖時腳底要落喺 canvas 底邊正中，四周留 8 px 透明邊。
- **可以溢出**：屋簷、旗、樹冠可以超出佔地，但**腳底必須對正佔地中心**，水平溢出 ≤ 0.5 tile（48 px）。
- **相鄰接縫**：相鄰 sprite 容許 1–2 px 重疊，避免露草地縫；但唔可以靠重疊去「偷位」改變佔地。
- **陰影**：唔好把陰影烘死喺 sprite（底圖除外）；建築用統一半透明橢圓陰影圖層，令 y 排序唔會出錯。
- **城牆分段**：北／南西／南東／西／東 分開出，唔好一整圈一張——唔係城內物件冇得夾前後。
- **命名**：`<zone_id>_<variant>_<w>x<h>.png`，例 `house_w_v1_130x100.png`。
- **畫布公式（2:1 等距，唔係 96 正方 AABB）**：
  - 地面投影闊 = `(w+h) × 48`；地面投影高 = `(w+h) × 24`
  - 畫布闊 = `(w+h) × 48 + 24`（左右各 12 px 出血）
  - 畫布高 = `(w+h) × 24 + H + 16`（H＝該資產立面高，JSON `sprite_rules.build_height_px` 已列）
  - 對照：官府 H=300 → 832×720；校場牆 H=140 → 784×536；南門 H=224 → 256×360；城牆段 4 tile、H=96 → 256×232。

## 5. 相機（影響你出圖嘅視角）

- 預設：16:9（基準 1280×720）、**zoom 0.5**、焦點 tile (13,10)、鏡頭邊界鎖 x1–26 / y1–18。
- **zoom 係鏡頭倍率**＝螢幕像素 / 投影世界像素。0.5 ＝ 投影平面 2304×1152 顯示成 1152×576，喺 1280×720 內左右留 64 px、上下留 72 px。
- 縮放範圍 **0.4 – 1.2**：0.4 睇全景（見埋城外草地），1.2 貼近官府／市場睇細節。1.0 以上會超出 artboard，背景草地要外擴 192 px。
- **即係話：出圖要為「半倍俯瞰」設計細節**，唔係為特寫設計。太細嘅紋理（<2 px）喺默認視角會消失，唔好花時間。
