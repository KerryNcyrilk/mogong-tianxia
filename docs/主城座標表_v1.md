# 主城座標表 v1

> 狀態：**PENDING**
> 來源：無。官方 31 區 cityLayout.json 仍未交來（檔案在 Kerry 的離線 PC，尚未進這個 repo）。本表不把 cityLayout.json，也不把任何其他副本，當作交付來源。沒有填入 31 區座標。

格子是正交整數格。每格 96×48 像素，棋盤 28 列 × 20 行。螢幕位置是 x = 欄 × 96、y = 列 × 48，沒有六角，也沒有額外的斜向投影。邏輯畫布是 2688×1920；20 列因此只佔 y 0–960，畫布下半是空白，不是多出來的列。區 id 用小寫 kebab-case，名稱用繁體中文。`role` 只允許 `building`、`reserve`、`pending-gameplay`。未指定玩法的區用 `pending-gameplay`，不另造角色名。層的固定順序是 ground → road → building → overlay。

`src/city/fixtures/city-layout.fixture.json` 有 12 區，只給載入器、結構、檢查器與預覽使用。那些矩形是合成的，不是下面這張表，也不會在官方檔到達前被抄進來。

## 格式

| 欄 | 說明 |
| --- | --- |
| id | 小寫 kebab-case，例如 `gov-office`、`campus`、`barracks` |
| 名稱 | 繁體中文 |
| role | `building`、`reserve`、`pending-gameplay` 三者之一 |
| layer | `ground`、`road`、`building`、`overlay` 之一 |
| x | 整數欄，0 起算 |
| y | 整數列，0 起算 |
| w | 整數寬，至少 1 |
| h | 整數高，至少 1 |
| builtin | `true` 或 `false` |

矩形必須落在 28×20 之內，區與區以半開區間計，邊相貼不算重疊。`campus` 必須能表示成 `role: building`，而且範圍內沒有其他區。
