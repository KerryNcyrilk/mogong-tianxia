| 條 | 按 v3.1 字面算出嚟嘅比值 | v3.1 期望 |
|---|---|---|
| E1 戟打騎 vs 戟打刀 | (2.2×1.3−2.0) / (2.2−1.0) = **0.717** | 1.3 |
| E2 學者打弓 vs 學者打盾 | (10×1.3−1.0) / (10−3.0) = **1.714** | 1.3 |
| E4 弓打盾 vs 弓打刀 | `2.6−3.0 < 0` → 下限 0.1 ／ `2.0−1.0 = 1.0` → **0.1** | 1.3 |

即係 **v3.1 嘅 E 組按字面根本測唔到 1.3**，係我規格側嘅缺陷，唔係 Rowan 實作錯。所以 E 組數字「全部 1.333」呢件事，一來對唔上 v3.1 字面，二來亦證明夾具（fixture）定義冇被鎖死。

## 1. §7.3 修正（取代 v3.1 §7.3，其餘照舊）

**E 組統一夾具（每條都必須係呢個形狀）**：

```
攻方：單一兵種、人數 N、無武將光環
靶 A：被剋兵種，def = 0（fixture 常數，唔入 balance.json）
靶 B：同 N、同 HP、def = 0 嘅中性靶（非被剋亦非剋攻方）
比較：同一回合、同一人數下嘅「最終傷害」單次輸出
比值：傷害(A) / 傷害(B)，期望 = COUNTER_MULT（1.3），容差 ±5%
```

**唯一變數係相剋乘數**。靶防一律 0、人數一律相等、冇光環、冇技能、冇反擊干擾。

| ID | 測咩 | 期望 |
|---|---|---|
| E1 | 戟打騎 vs 戟打中性靶（def 0） | 1.3×±5% |
| E2 | 學者打弓 vs 學者打中性靶 | 1.3×±5% |
| E3 | 騎打學者 vs 騎打中性靶 | 1.3×±5% |
| E4 | 弓打盾 vs 弓打中性靶 | 1.3×±5% |
| E5 | 盾打刀 vs 盾打中性靶 | 1.3×±5% |
| E6 | 刀打戟 vs 刀打中性靶 | 1.3×±5% |
| E7 | **弓打學者 vs 弓打中性靶** | **= 1.0（唔加乘）** |
| E8 | **學者打盾 vs 學者打中性靶** | **= 1.0（唔加乘）** |

**比值要係浮點、唔可以係整數除法**：傷害用 float 比較（或比較 `攻'×相剋` 嘅乘數段），唔准用 `floor` 後嘅減員數做比值 —— 用整數會出 4/3＝1.333 呢類假象，掩蓋乘數本身嘅錯。
