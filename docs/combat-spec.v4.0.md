## 3. 傷害公式

\[

\text{dmg} = \lfloor (\text{ATK} \times C - \text{DEF}) \times M \rfloor

\]

- `C` ＝ 第 2 節的相克系數
- `M` ＝ 士氣系數，預設 `1.00`；靶兵場測可指定 `0.75` 或 `1.25`
- 中間全用浮點，**只在最後一步取整**，取整方式為向下取整（floor）
- 結果下限夾在 **0**（負數一律當 0，唔准出現「治療」效果）
- `DEF` 取防守方當前 `def`，唔做遞減、唔做百分比減傷

**超殺唔限制**：dmg 可以大於目標剩餘 hp，超出部分丟棄（不做溢出轉移）。

## 4. 出手序

1. 每回合開始，按 `spd` 由高到低排一次出手序（唔按敏捷浮動、無隨機）。
2. `spd` 相同 → **攻方先**。
3. 同一方內部 `spd` 再相同 → 按陣位 index 升序（0 在最前）。
4. 死掉的單位即時從本回合剩餘出手序中移除。
5. 出手序**每回合重算一次**，唔跨回合沿用。

一回合流程：`排出手序 → 逐個出手（攻方對守方、守方對攻方，各自指向當前最近的敵方單位）→ 回合結束 → 檢查勝負`

---

## 5. 勝負判定

按以下順序，命中即停：

1. 任一方全滅 → 另一方勝（不看回合數）
2. 回合數到 **15** 仍未分出 → **攻方敗**（防守方勝）
3. 同回合雙方同時全滅（即最後兩擊互殺）→ 判**守方勝**（攻方敗），理由：防守方達成防守目的

判定函數必須是純函數，輸出 `{winner: "attacker"|"defender", turns: number, reason: string}`。

三隻測試單位，`def` 一律 0，`tier = "test"`，唔參與正常戰鬥。

| id | atk | def | hp | 用途 | 期望 dmg |
|---|---|---|---|---|---|
| `TARGET-A1` | 1000 | 0 | 99999 | 公式基本盤（C=1.00, M=1.00） | **1,000** |
| `TARGET-A2` | 1000 | 0 | 99999 | 相克剋制（C=1.25, M=1.00） | **1,250** |
| `TARGET-A5` | 5832 | 0 | 99999 | **錨點**（C=1.00, M=0.75） | **4,374** |

A5 算式：`5832 × 1.00 × 0.75 = 4374`，取整後恰好 4,374，**一位都不能差**。這個數是全份規格的地基：任何改動公式、系數、取整方式的提案，都要先答「A5 還是不是 4,374」。
