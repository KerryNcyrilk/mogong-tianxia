# B6 武將與成長規格 v0.1

狀態：**v0.1 已實作**（2026-11-25，豆包）。真源：`data/generals.json`（`generals.v1.0`）＋`src/general/{types,config,engine}.ts`。

## 1. 武將屬性
- 四原型：猛將（攻18/防10/統6）、智將（12/12/10）、統帥（10/16/14）、儒將（8/8/16）。
- 等級 1–60；每級成長 攻 +3 / 防 +2 / 統 +1。
- 帶兵上限 = (600 + 統率 × 120) × (1 + 兵法被動)。裝備的統率加成同樣計入。
- 派生值只由 `statsOf()` 一處計算，UI 與戰棋不得自行加總。

## 2. 經驗與升級
- `expToNext(lv) = round(100 × 1.35^(lv-1))`：Lv.1→2 需 100，2→3 需 135，3→4 需 182。
- 一次可跨多級（`gainExp` while 迴圈），升級後餘額保留；滿 60 級清零並封頂。
- 經驗來源：B6 只提供 API 與校場練兵（列陣武將每小時 +12）；戰後獎勵等 B7 結算。

## 3. 裝備
- 三槽：weapon／armor／horse；六件樣本（青龍刀 +12攻、鐵甲 +14防、的盧 +6統、角弓 +9攻+2統、皮盾 +8防、烏號馬 +3攻+2防+3統）。
- 同槽替換即覆蓋；換下不回收、不入庫（v0.1 簡化，B8 再做庫存）。

## 4. 技能
| id | 名 | 類型 | 效果 |
|---|---|---|---|
| sk_huoji | 火計 | 主動 | 射程 3、傷害 ×1.4、冷卻 2 回合 |
| sk_tuji | 突擊 | 主動 | 射程 1、傷害 ×1.15、冷卻 1 回合 |
| sk_sishou | 死守 | 被動 | 統率部隊防禦 +15% |
| sk_bingfa | 兵法 | 被動 | 帶兵上限 +10% |

- 主動技能走 B2 預留接口 `applyCommand({type:"skill"})`：`BoardUnit.skills`＋`cd`，`reason` 增 `no-skill`／`cooling`；傷害仍用同一 `calcDamage()`，再乘 `power`。
- 冷卻在每回合結束（turn+1）統一減 1；託管 AI 有技能就先用技能，再退回普攻／移動，命令序列仍可重放。

## 5. 酒館與編隊
- 酒館每日三名候選（同日同結果，`dayKey` 決定），招募花 刀幣 2000 + 玉石 1；已招募者不再出現。
- 校場三格，每格「一將＋一兵種＋兵數」；兵數 ≤ min(帶兵上限, 兵池)，同一武將不可佔兩格；撤格回池。
- 兵力七行（刀/戟/弓/盾/騎/學/神獸）＝兵池即時值，主城左欄直接綁這一份。
