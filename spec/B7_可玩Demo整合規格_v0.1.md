# B7 可玩 Demo 整合規格 v0.1（草案）

狀態：**草案，未實作**。本文件只定閉環與接口，不動 B7 整合碼。

## 1. 目標閉環
主城內政 → 徵兵與武將編隊 → 出城進 B2 12×8 手動戰棋 → 戰後獎勵與傷兵回城。

## 2. 五段接口

### 2.1 內政 → 徵兵
- 入口：主城左欄兵力七行「＋」→ 徵兵面板。
- 消耗：刀幣＋糧食＋人口（每 100 兵：刀幣 300、糧 120、人口 1），受人口上限與兵種上限約束。
- 產出：寫入 `RosterState.troops[unit]`，即時反映到左欄七行。
- 拒絕理由固定三值：`no-resource`／`pop-cap`／`unknown-unit`。

### 2.2 編隊 → 出戰
- 校場三格即出征陣容（B6 已實作）；點「出城」把三格轉成 `Squad[]`，武將屬性經 `battleGeneral()` 轉 `General`（含主動技能）。
- 三格不足一格時禁止出戰（`empty-formation`）。

### 2.3 戰棋
- 沿用 B2 手動棋盤；技能走 B6 已落地的 `skill` 命令。
- 新增「撤退」：主動撤退保留 70% 兵力，判負但不算全滅。

### 2.4 戰後結算
- 勝：經驗 = 敵方總兵力 × 0.6，均分給三格武將；戰利品 刀幣 = 敵方兵力 × 2。
- 敗：經驗 = 擊殺兵力 × 0.4；傷兵 = 出戰兵力的 40% 回池，其餘損失。
- 士氣：勝 +5、敗 −8（夾在 0–100）。

### 2.5 回城
- 傷兵回池後重算七行；武將經驗即時寫檔；戰報一條入 `internal.eventLog`（kind `battle`）。

## 3. 驗收（B7 實作時）
1. 一條命令能從主城走到戰棋再回城，中途不需重整頁面。
2. 戰後七行兵力、武將等級、刀幣三者數值可對帳（初值 → 戰後 → 存檔重載一致）。
3. 四項自證同 B6：行號對照、gate 實跑、1280/1920 截圖、紅線零改。
