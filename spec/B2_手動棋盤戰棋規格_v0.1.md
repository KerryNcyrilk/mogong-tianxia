# B2 · 手動棋盤戰棋規格 v0.1（草案）

狀態：草案｜作者：豆包｜日期：2026-11-25｜依據：`COMBAT-B2-MANUAL-RULING`、`docs/combat-spec.v4.0.md`、`data/units.v4.0.json`、`tests/anchors.test.ts`
**本文件不改任何戰鬥碼**；B2 於 B5 交付後開工。

## 0. 一句話
把現有自動戰鬥收斂成 **12×8 棋盤手動回合制**：玩家逐格下「移動／攻擊／待機」，敵方由 AI 行動，並保留一顆「自動託管」切換掣。

## 1. 邊界
1. 沿用 `units.v4.0.json` 兵種數值與 `anchors.test.ts` 的 A1–A5 錨點公式（不得改 A1–A5）。
2. 戰場格固定 `12×8`；將領不佔格、不佔名額（既有錨點）。
3. B5 期間禁改 `src/combat/**`；B2 動工後只准在 `core.ts`／`battle.ts` 收斂，不改 `balance.json` 常數。

## 2. 回合結構
- 一回合 = 我方全體行動 → 敵方行動 → 結算（士氣／傷亡／增益到期）。
- 行動序：速度高者先行；同速攻方先（對應錨點 E）。
- 每單位每回合一個「行動點」：移動（≤ move 格）＋ 攻擊（射程內）或 待機（回 30% 行動點，下回合 +1 移動）。
- 攻擊後不可再移動；移動後可攻擊，前提是移動結束時與目標距離 ≤ 射程。

## 3. 指令 API（給 UI 與 AI 共用）
```ts
type Command =
  | { type: "move"; unitId: string; to: { x: number; y: number } }
  | { type: "attack"; unitId: string; targetId: string }
  | { type: "wait"; unitId: string }
  | { type: "toggleAuto"; enabled: boolean }
```
- `applyCommand(state, command)` 回傳 `{ state, ok, reason }`；`reason` 只三種：`not-your-turn`／`out-of-range`／`blocked`。
- UI 只准透過 `applyCommand`，不得直接改棋盤陣列。
- `toggleAuto(true)` 後每回合由 `autoTurn(state)` 產生同一組 Command，玩家可隨時 `toggleAuto(false)` 接回。

## 4. 移動與射程
- 棋盤 12×8，正交四方向尋路（無對角），一格一步；被佔格不可穿越（可繞行）。
- 每兵種補 `move` 欄位（`units.v4.0.json` 缺）：刀 3／戟 2／弓 2／盾 2／騎 4／學者 2／神獸 3。
- 射程：弓 4、學者 3（法術）、其餘 1；射程以「曼哈頓距離」計，障礙物不阻視線（v0.1 簡化）。
- 移動力受地形？v0.1 不做地形，全場平地。

## 5. 自動託管
- 預設 **關**（手動）；開啟後敵我皆 AI，玩家只可 `toggleAuto(false)` 取回。
- AI 規則 v0.1（可預測、可測試）：優先攻擊射程內血量最低目標；否則向最近敵方直線靠近至移動力上限；無敵方則待機。
- 託管期間不得顯示「玩家可下指令」樣式。

## 6. UI 綁定（不改座標）
- 棋盤沿用現有 `public/art/board/*` 與 12×8 格。
- 選中單位顯示可移動格（金色邊、2 px）與可攻擊格（朱紅邊）；顏色限 `ui-check` 白名單 11 色。
- 右下角加一顆 `auto` 切換掣（40×32，`hit: control`，文字「託管／手動」），不新增畫布節點時可借 `initiative` 位。
- 傷害飄字沿用現有 `damage` 節點，不新增字體尺寸。

## 7. 驗收（GB2-0…GB2-6，B2 動工後跑）
- **GB2-0** 既有 80 tests 全過；A1–A5 錨點逐位不變。
- **GB2-1** 一格一步：`move` 到距離 > move 的格 → `ok:false, reason:"blocked"`。
- **GB2-2** 射程：弓箭手距 4 可攻、距 5 不可（`out-of-range`）。
- **GB2-3** 佔格：目標格有單位 → `blocked`；繞行可達。
- **GB2-4** 回合序：同速攻方先行（對應錨點 E）＋ 士氣結算與 v4.0 一致。
- **GB2-5** 託管：同一 seed 下 `autoTurn` 逐回合輸出可重現（JSON 比對）。
- **GB2-6** prod：`window.__syslog__` 仍 undefined；bundle 差 ≤ 0.3 KB。
